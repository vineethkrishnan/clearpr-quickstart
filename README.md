# clearpr-quickstart

A tiny demo repo used in ClearPR's [Setup Walkthrough](https://github.com/vineethkrishnan/clearpr/blob/main/docs-site/guide/setup-walkthrough.md).

The PRs in this repo show what ClearPR's semantic diff filtering looks like:
formatting noise (Prettier, semicolons, quote style) gets stripped, the real
behavior change shines through, and the AI review focuses on the change that
matters.

If you want to try ClearPR on real code, install it on your own repos.
